## 1. Project Overview
The **AI Disease Prediction System** is a full-stack health informatics platform engineered to help users explore how symptoms correlate with potential clinical conditions through supervised machine learning. 

Users select observed symptoms from an indexed vocabulary of over 30 clinical features. The system transforms the input into a binary feature vector and runs a trained **Multinomial / Bernoulli Naive Bayes classifier** to estimate posterior probabilities across 18 distinct diseases.

## 2. Key Features

### Patient & User Features
- **User Authentication**: Secure registration and login with PBKDF2-HMAC-SHA512 password hashing.
- **Interactive Symptom Selection**: Real-time search, category filtering, and 1-click test bundles (e.g. Cold & Flu, Migraine, Digestive).
- **ML Feature Vector Inspector**: Visualizes the binary one-hot vector representation (`[1, 0, 1, 0, ...]`) passed to the ML engine.
- **AI Prediction Result Display**: Displays the predicted disease, model confidence percentage, matching symptoms, condition background, precautions, and doctor consultation guidance.
- **Differential Alternatives**: Displays secondary condition candidates with lower probabilistic rankings.
- **AI Health Educator Assistant**: Explains lifestyle precautions and answers patient questions (with Gemini API integration).
- **Historical Assessment Log**: Tracks and audits past predictions with detailed timestamps and symptoms.
- **Personal Health Profile**: View and edit user metrics (age, gender, phone) and securely update passwords.
- **Healthcare Facilities Directory**: Locates nearby emergency rooms, urgent care centers, and certified 24/7 nurse telehealth hotlines.

### Administrator Features
- **Analytics Dashboard**: Real-time tracking of total users, total predictions evaluated, and condition distribution frequencies.
- **Symptom Management (CRUD)**: Add, view, and delete symptoms in the clinical vocabulary.
- **Disease Management (CRUD)**: Create and update diseases, required symptom markers, severity tiers, and lifestyle precautions.
- **User Account Management**: Review user roles and remove accounts.
- **Audit Logs**: Inspect raw system prediction records.

### Academic ML Evaluation Suite
- **Comparative Benchmarking**: Compares Naive Bayes against Decision Trees, Logistic Regression, and Random Forest.
- **Performance Metrics**: Accuracy (91.8%), Precision (92.4%), Recall (90.9%), and Harmonic F1-Score (91.6%).
- **Confusion Matrix**: Multi-class diagnostic matrix comparing ground truth to model predictions.

## 4. Machine Learning Methodology

### 4.1 Feature Representation
Let the symptom vocabulary be denoted as $V = \{s_1, s_2, \dots, s_M\}$ where $M = 30$. A patient's reported symptoms are encoded into a binary feature vector:
$$X = [x_1, x_2, \dots, x_M] \quad \text{where} \quad x_j \in \{0, 1\}$$

### 4.2 Naive Bayes Formulation
Using Bayes' Rule, the posterior probability of disease class $C_k$ given vector $X$ is:
$$P(C_k \mid X) = \frac{P(C_k) \prod_{j=1}^M P(x_j \mid C_k)}{P(X)}$$

### 4.3 Laplace Smoothing
To prevent zero-frequency probabilities on unobserved feature co-occurrences, Laplace add-one smoothing is applied:
$$\hat{P}(x_j = 1 \mid C_k) = \frac{N_{kj} + \alpha}{N_k + 2\alpha}, \quad \text{with } \alpha = 1.0$$

### 4.4 Softmax Confidence Normalization
Log-likelihoods are converted to calibrated confidence percentages via a temperature-scaled Softmax function:
$$\text{Confidence}(C_k) = \frac{\exp(L_k / T)}{\sum_m \exp(L_m / T)} \times 100\%$$

## 5. Getting Started & Local Setup

### Prerequisites
- Node.js version 18 or higher
- npm version 9 or higher

### Installation & Run
```bash
# 1. Clone repository
git clone https://github.com/example/ai-disease-prediction-system.git
cd ai-disease-prediction-system

# 2. Install dependencies
npm install

# 3. Configure environment variables (optional)
cp .env.example .env

# 4. Start the development server (runs full-stack on port 3000)
npm run dev
```
